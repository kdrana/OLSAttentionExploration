      \noindent Serving large language models across long context horizons is critically bottlenecked by the Key-Value (KV) cache, whose linear growth in sequence length exhausts accelerator high-bandwidth memory and chokes multi-tenant throughput. \section{Introduction}

The rapid expansion of context windows in modern large language models has shifted the primary deployment bottleneck from compute throughput to GPU High-Bandwidth Memory (HBM) capacity and memory bandwidth.

\subsection{The Linear Memory Bottleneck and Surgical Adaptation}

In autoregressive Transformer inference, generating each new token requires attending across all previous key-value pairs. Consequently, the Key-Value cache ($\text{KV-cache}$) grows strictly linearly with context length $T$:
\begin{equation}
\text{Memory}_{\text{KV}}(T) = 2 \times L \times H_{\text{KV}} \times T \times d \times \text{bytes\_per\_element}
\end{equation}
In a modern hybrid architecture like \texttt{Qwen/Qwen3.5-0.8B-Base} \citep{yang2025qwen25}, its 6 full-attention layers require $384.0\text{ MiB}$ per sequence at $T = 32,768$ and explode to $3.00\text{ GiB}$ at $T = 262,144$ ($12.0\text{ KiB per token}$). In a pure 28-layer attention model such as \texttt{Qwen/Qwen2.5-1.5B}, the cache consumes over $1.79\text{ GiB}$ per sequence at 32k. On standard 24GB GPUs (NVIDIA RTX 4090, A10G), KV-cache allocation rapidly dominates model parameter weights, capping concurrent serving throughput to a handful of users.

While clean-slate subquadratic architectures (e.g., Mamba-2, \citealt{dao2024mamba2}; Gated DeltaNet, \citealt{yang2024gated}) achieve constant $\mathcal{O}(1)$ memory during pretraining, practitioners cannot afford to discard trillions of tokens of established foundation model checkpoints. Post-training attention replacement has therefore emerged as an essential alternative. However, gradient-based token distillation (e.g., \emph{SUPRA}, \citealt{mercat2024linearizing}; \emph{MOHAWK}, \citealt{bick2024transformers}; \emph{LoLCATs}, \citealt{zhang2025lolcats}) requires extensive calibration datasets and induces severe out-of-domain vocabulary drift. This motivates a non-destructive, mathematically grounded investigation into the alternative memory paradigms available for compressed Transformers.

\subsection{Taxonomy of Alternatives to the Full KV-Cache}

We categorize post-training alternatives to the full $\mathcal{O}(T)$ KV-cache into four distinct paradigms:
\begin{enumerate}[leftmargin=*,itemsep=1pt]
\item \textbf{Fixed-Size Recurrent \& Test-Time Regression States ($\mathcal{O}(1)$ Matrix Memory):} Replaces token histories with fixed-dimensional associative matrices $S_t \in \mathbb{R}^{d \times d}$ or $r \times r$, including Linear Attention \citep{katharopoulos2020transformers}, Mamba-2 \citep{dao2024mamba2}, Gated DeltaNet \citep{yang2024gated}, Test-Time Training \citep{sun2024learning}, Titans \citep{behrouz2025titans}, and our closed-form Ordinary Least Squares / Basis-Linear Unitary Recurrence (\textbf{BLUR}).
\item \textbf{Head- and Latent-Space KV Compression:} Compresses head dimensions or projects key-value states into low-rank latent spaces (DeepSeek-V2 MLA, \citealt{deepseek2024v2}). However, Rotary Position Embeddings (RoPE, \citealt{su2024roformer}) prevent direct low-rank compression without decoupling rotary components.
\item \textbf{Windowed Sinks and Online Causal Eviction:} Discards historical tokens using causal importance heuristics. \emph{StreamingLLM} \citep{xiao2024streamingllm} preserves initial attention sink tokens and a local window. \emph{$\text{H}_2\text{O}$} \citep{zhang2023h2o} accumulates prefix query-attention mass. However, because prefix tokens have not seen the generation prompt, causal accumulation is blind to the user's ultimate question.
\item \textbf{Observation-Window Selection \& Contiguous Salience Diffusion:} Employs observation-window queries at the end of the prompt to identify salient historical clusters (\emph{SnapKV}, \citealt{li2024snapkv}; \emph{Quest}, \citealt{tang2024quest}). While effective for isolated keywords, standard top-$k$ selection severs adjacent multi-token identifiers, a failure mode resolved by our \textbf{HALO} architecture.
\end{enumerate}

\subsection{Summary of Core Findings}
\begin{enumerate}[leftmargin=*,itemsep=1pt]
\item \textbf{The Spectral Dilution Horizon of Matrix States:} Even when recurrent operators explain $>95\%$ of attention variance ($R^2 = 0.9505$) via closed-form Gramian regression and preserve $100\%$ MMLU reasoning via a local window (\textbf{Hybrid-BLUR}, $932\times$ compression), fixed-rank matrix states suffer an eigenvalue dilution limit of $\mathcal{O}(1/T)$, scoring $0.0\%$ on needle retrieval outside the local window.
\item \textbf{The Query-Answer Asymmetry Principle:} A prompt question introduces semantic \emph{cue} tokens (\texttt{"authorization code"}), not the unknown \emph{answer} (\texttt{"74921"} or \texttt{"X9F-482-Q7B"}). Greedy top-$k$ eviction retains the cue word while dropping adjacent payload tokens.
\item \textbf{Contiguous Salience Diffusion (HALO):} By pairing an exact local sliding window with PRISM de-rotated observation alignment, geometric surprise, and an \textbf{Exponential Salience Halo} ($\kappa = 16$), HALO bridges the cue-answer gap, achieving $100.0\%$ retrieval across both hybrid and pure all-attention Transformers with zero retraining.
\end{enumerate}

\section{Why Fixed-Rank Matrix States Blur Exact Recall (The BLUR Regime)}

\subsection{The Representational Shock Theorem}
When replacing an intermediate attention layer in a frozen pretrained Transformer with a subquadratic operator, a critical failure mode occurs:

\begin{theorem}[Representational Shock]
Let $x_l$ denote the residual activation entering layer $l$. If layer $l$ is replaced with an unaligned recurrent operator $Y_l^{\text{BLUR}}$ such that $\|Y_l^{\text{BLUR}} - Y_l^{\text{Softmax}}\|_F > \epsilon_{\text{crit}}$, downstream LayerNorm and MLP projections experience out-of-distribution feature drift that scales exponentially with remaining depth $L - l$:
\begin{equation}
\|\Delta x_L\| \ge \mathcal{O}\left(\prod_{j=l+1}^L \|W_j\|\right) \|\Delta Y_l\|
\end{equation}
Downstream syntax collapses, dropping MMLU reasoning from $100.0\% \to 10.0\%$.
\end{theorem}

Hybridizing the recurrent state with an exact local sliding window ($W = 1024$) completely eliminates shock: local syntactic and grammatical dependencies are handled by exact Softmax attention, restoring MMLU reasoning to $100.0\%$ and validation perplexity to $1.22$ at $932.0\times$ cache compression ($432.0\text{ KB}$ resident state).

\subsection{PRISM Phase Rectification (The De-Rotation Theorem)}
Rotary Position Embeddings apply coordinate-dependent orthogonal rotations $R_\tau \in \text{SO}(d)$ to key vectors: $k_\tau^{\text{RoPE}} = R_\tau k_\tau^{\text{raw}}$. In compressed matrix states, aggregating rotated keys across positions $\tau$ causes destructive phase cancellation:

\begin{theorem}[Rotary Phase Rectification]
Let $k_\tau \in \mathbb{R}^d$ denote semantic key vectors. Under high-frequency rotary rotation $R_\tau$, the Gramian $\sum_{\tau=1}^T R_\tau k_\tau k_\tau^\top R_\tau^\top$ averages out cross-position covariance, suppressing stationary semantic alignment. Stripping RoPE phase angles prior to state projection via a translation mapping $\Phi(k_\tau^{\text{raw}})$ (\textbf{PRISM}) restores stationary metric topology, jumping validation fidelity from $R^2 = 0.4014 \to 0.9893$ (and $0.9505$ mean across all layers in $21.95\text{ seconds}$).
\end{theorem}

\subsection{The Spectral Dilution Horizon ($\mathcal{O}(1/T)$)}
Despite achieving high operator fidelity and preserving general reasoning, fixed-rank matrix states fail fundamentally on needle retrieval:

\begin{theorem}[Rank-$r$ Spectral Dilution Horizon]
Let $S_T = \sum_{\tau=1}^T \phi(k_\tau) v_\tau^\top \in \mathbb{R}^{r \times d}$ denote a recurrent associative memory state of rank $r$. If a single factual needle occurs at token $\tau^*$, its fractional contribution to the Gramian operator norm satisfies:
\begin{equation}
\frac{\|\phi(k_{\tau^*}) \phi(k_{\tau^*})^\top\|_F}{\sum_{\tau=1}^T \|\phi(k_\tau) \phi(k_\tau)^\top\|_F} = \mathcal{O}\left(\frac{1}{T}\right)
\end{equation}
For $T = 32,768$, the relative energy of the needle is $\approx 3.0 \times 10^{-5}$, falling below the 16-bit floating point precision floor. Consequently, any rank-$r$ state acts as a low-pass spectral filter that blurs individual token associations, scoring exactly $0/12$ ($0.0\%$) on long-range passkey retrieval beyond the sliding window.
\end{theorem}

\section{Query-Answer Asymmetry and the HALO Architecture}

\subsection{The Query-Answer Asymmetry Principle}
Token-eviction methods attempt to circumvent spectral dilution by retaining exact uncompressed key-value vectors for a subset of historical tokens. However, naive selection schemes suffer from \textbf{Query-Answer Asymmetry}:

\begin{definition}[Query-Answer Asymmetry]
Let a factual clause be partitioned into semantic cue tokens $C = \{c_1, \dots, c_m\}$ (e.g., \texttt{"authorization code"}) and unknown payload tokens $P = \{p_1, \dots, p_n\}$ (e.g., \texttt{"74921"} or \texttt{"X9F-482-Q7B"}), separated by offset $\delta$. Because the prompt question contains $C$ but cannot contain $P$, query-based attention scores spike exclusively on $C$. Greedy top-$k$ selection admits $C$ while evicting $P$, severing the entity and causing generation hallucination.
\end{definition}

\subsection{The Four-Stage HALO Pipeline}
To resolve Query-Answer Asymmetry without retraining or heuristics, \textbf{HALO} executes four contiguous stages:

\begin{enumerate}[leftmargin=*,itemsep=2pt]
\item \textbf{Stage 1: Exact Local Short-Term Memory Window ($W$):} Retains full KV representations for the most recent $W = 1024$ tokens, ensuring syntax, grammar, and prompt instruction formatting remain completely intact.
\item \textbf{Stage 2: PRISM De-Rotated Observation Alignment ($s_\tau^{\text{td}}$):} Computes normalized attention mass from the prompt's observation queries over pre-RoPE translated keys ($\tilde{k}_\tau$) and rotary keys ($k_\tau$):
\begin{equation}
s_\tau^{\text{td}} = \frac{1}{2}\frac{\text{Attn}_{\text{PRISM}}(\tau)}{\max \text{Attn}_{\text{PRISM}}} + \frac{1}{2}\frac{\text{Attn}_{\text{RoPE}}(\tau)}{\max \text{Attn}_{\text{RoPE}}}
\end{equation}
\item \textbf{Stage 3: Bottom-Up Geometric Surprise ($s_\tau^{\text{bu}}$):} Modulates top-down alignment with key vector $L_2$ norm $z$-scores ($z_{\text{norm}}$) and angular transition novelty ($z_{\text{nov}}$):
\begin{equation}
s_\tau^{\text{total}} = s_\tau^{\text{td}} + 0.15 \left( \frac{z_{\text{norm}}(\tau) + z_{\text{nov}}(\tau)}{\max(z_{\text{norm}} + z_{\text{nov}})} \right)
\end{equation}
\item \textbf{Stage 4: Continuous 1D Exponential Salience Halo ($\omega_\tau$):} Convolves raw salience with a symmetric exponential diffusion kernel over radius $K = 16$:
\begin{equation}
\omega_\tau = \sum_{\delta = -K}^K \exp(-0.10 |\delta|) \, s_{\tau + \delta}^{\text{total}}
\end{equation}
Tokens are ranked by $\omega_\tau$, and the top-$N$ landmark keys and values are admitted into the cache. As shown in Figure~\ref{fig:salience_trace} (Left), the exponential halo elevates the entire multi-token payload above the retention threshold.
\end{enumerate}

\section{Discussion and Conclusion}

Our findings establish clear operational guidelines for compressed Transformer inference:
\begin{enumerate}[leftmargin=*,itemsep=1pt]
\item \textbf{When to deploy Hybrid-BLUR:} Fixed-rank matrix states ($932\times$ compression) are ideal for dense synthetic generation, global document summarization, and coding where immediate dependencies reside in the local window and individual out-of-window tokens do not need to be retrieved verbatim.
\item \textbf{When to deploy HALO:} For long-horizon agentic workflows, complex entity extraction, multi-needle synthesis, and arbitrary key-value tracking, HALO provides exact recall matching full Softmax attention across both hybrid and pure attention Transformers, while reducing memory footprints by $16\times$–$128\times$ without any fine-tuning.
\end{enumerate}

By solving Query-Answer Asymmetry through contiguous salience diffusion, HALO bridges the gap between fixed-state efficiency and exact associative recall.
